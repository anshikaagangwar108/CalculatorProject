# Calculator Project

## Description

This is a simple Calculator Project developed in C programming language. The calculator performs basic and advanced mathematical operations through a menu-driven interface. It is designed to help users perform calculations easily and efficiently.

## Features

* Addition
* Subtraction
* Multiplication
* Division
* Modulus
* Percentage
* Square
* Square Root
*Power
* User-friendly Menu Interface

## Technologies Used

* C Programming Language
* Visual Studio Code (VS Code)
* GCC Compiler

## How to Run

1. Clone the repository:

   ```bash
   git clone <repository-link>
   ```

2. Open the project folder in VS Code.

3. Compile the program:

   ```bash
   gcc calculator.c -o calculator -lm
   ```

4. Run the executable:

   ```bash
   ./calculator
   ```
